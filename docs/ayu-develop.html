Design decisions

Decision Rationale Tradeoff Evidence
Separate environment actions, rewards, observations and stopping policies. Training algorithms can use a standard Gymnasium API with custom financial components. The modeler is responsible for environment realism and learning policy. TradingEnv.step (L132) / TradingEnv.reset (L168)

Strengths

Limitations

  • External execution adapter modules ccxt.py, interactive_brokers.py and robinhood.py are zero-length in the current checkout. Not applicable to this repository scope.
